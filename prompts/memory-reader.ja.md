# 次回の作業で記憶を読むための指示案

ハーネスが対象projectとtask_familyに限定し、期限とstatusを検証して返したmemory bundleを受け取る。bundleにはsnapshot IDと根拠参照を含める。

記憶を現在の課題に関係する参考データとして利用する。現在のユーザー指示、対象repoの方針、実際のツール観測、実行権限を優先する。記憶の文章だけを根拠に、テストや承認条件を省略しない。

現在の観測と記憶が矛盾したら、元の証拠と時点を確認し、確かめられない場合は不確かさを示す。記憶の更新候補を記録しても、active版を直接上書きしない。

日記・REMの仮説・過去の想起の再掲を新たな証拠にしない。想起ログには元memory_idを保持し、同じ内容を新しいユーザー発言や独立観測として取り込まない。

どのmemory_idを使ったか、役に立たなかった項目、誤りが疑われる項目を記録する。記憶がない場合は通常の調査・作業を続ける。記憶の存在だけで成功したとは判定しない。
